# Crime Safety Analysis Dashboard

Exploratory data analysis of 1,000 crime records, uncovering victim age and time-of-day patterns across crime types and cities — presented through an interactive Gradio dashboard, alongside a transparently-evaluated prediction model.

## 📌 Overview

This project analyzes a dataset of 1,000 reported crime cases to understand who is most affected by crime, and when. It combines exploratory data analysis with a machine learning classifier, and presents the findings through an interactive dashboard.

Key questions explored:
- Which age groups are most frequently targeted by crime?
- How do victim age patterns shift across different times of day?
- Do specific crime types (e.g. Burglary, Domestic Violence) show distinct age or time patterns?
- Can crime type be predicted from contextual features like city, age, and time?

## 🎯 Objectives

- Clean and explore the crime safety dataset
- Engineer time-of-day and age-bracket features from raw timestamps and ages
- Visualize age, time, and crime-type patterns using Matplotlib and Seaborn
- Train and honestly evaluate a classification model to predict crime type
- Present all findings through an interactive Gradio dashboard

## 📊 Dataset

`crime_safety_dataset.csv` contains 1,000 rows, each representing a reported crime case, with the following columns:

| Column | Description |
|---|---|
| id, date, time | Case identifier and timestamp |
| crime_type | One of 10 crime categories (Arson, Assault, Burglary, Domestic Violence, Drug Offense, Fraud, Homicide, Robbery, Theft, Vandalism) |
| city, state, location_description | Location context |
| victim_age, victim_gender, victim_race | Victim demographics |

Two engineered features are added during analysis:
- **time_period** — Morning, Afternoon, Evening, or Night, derived from the timestamp
- **age_bracket** — 30 or Below, 31-40, 41-50, 51-60, or 60+, derived from victim age

## 🚀 Usage

**Generate charts standalone:**
```bash
python graph_chart.py
```

**Train the model:**
```bash
python model.py
```
Loads the dataset, trains a Random Forest Classifier, prints accuracy and a classification report, and saves the trained model to `crime_model.pkl`.

**Launch the dashboard:**
```bash
python app.py
```
Make sure `crime_safety_dataset.csv` is in the same folder as `app.py`. The dashboard opens in your browser with four tabs: Overview, Age Analysis, Crime & City Patterns, and a Predict Crime Type tool.

## 📈 Key Insights

- **Victims aged 60+ are the most frequently targeted age group**, accounting for 405 of 1,000 cases — far more than any other age bracket.
- During **evening and night hours**, the average victim age rises to ~52 years (mean 51.9, median 52, mode 52), noticeably older than the dataset's overall spread.
- **Burglary** peaks sharply in the **morning** among the 60+ age group (20 cases) — likely reflecting increased vulnerability when homes are left with only elderly residents present during typical work hours.
- **Domestic Violence** shows a consistently high rate among the 60+ group throughout the day, except at night, when younger victims (30 and below) become more common.
- A city-vs-crime-type crosstab shows crime types are **fairly evenly distributed across cities** — no single city is disproportionately affected by any one crime type.

## 🤖 Modeling Approach

- **Problem type:** Classification (predicting crime type)
- **Target variable:** crime_type (10 classes)
- **Features used:** city, age_bracket, time_period, victim_gender, victim_race, state
- **Model:** Random Forest Classifier
- **Preprocessing:** One-hot encoding for all categorical features
- **Evaluation metrics:** Accuracy, precision/recall/F1 (classification report)

## 📌 Results

| Model | Metric | Score |
|-------|--------|-------|
| Random Forest Classifier | Accuracy | ~11.5% |

**Honest finding:** With 10 crime categories, random guessing would achieve roughly 10% accuracy. The trained model's ~11.5% accuracy is only marginally better than chance. A crosstab of city against crime type confirmed that crime types are nearly uniformly distributed across cities, indicating no strong relationship between the available contextual features (city, age, time, gender, race, state) and crime type in this dataset. The prediction tool is included in the dashboard for transparency and completeness, not because it is highly reliable — the real value of this project lies in its exploratory findings on victim age and time patterns.
